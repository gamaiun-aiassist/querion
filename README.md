# Querion — лендинг

Статический сайт ИИ-помощника Querion: главная страница, политика конфиденциальности и страница 404. Чистые HTML, CSS и немного JS, без фреймворков, сборщика и внешних запросов. Хостинг — GitHub Pages из ветки `main`, корень репозитория.

## Структура

```
index.html            главная страница
privacy.html          политика конфиденциальности (текст — заглушка)
404.html              страница «не найдено»
favicon.svg
robots.txt
.nojekyll             отключает сборку Jekyll на GitHub Pages
assets/
  css/styles.css      токены, типографика, стили
  js/main.js          мобильное меню, подсветка фрагментов, переключатель ролей, проявление картинок
  fonts/              Golos Text (woff2, лицензия OFL)
  img/                логотип, скриншоты (WebP + PNG), og-image.png
```

## Локальный запуск

Сборка не нужна. Любой статический сервер из корня:

```bash
npx http-server -p 8080 -c-1 .
# или
python3 -m http.server 8080
```

## Правка контента

- Тексты — прямо в `index.html`: «е» вместо «ё», без точки в конце абзаца и пункта, неразрывный пробел после однобуквенных предлогов и союзов (`в&nbsp;`, `и&nbsp;`), `4–6&nbsp;недель`.
- Цвета и радиусы — переменные в `:root` в начале `assets/css/styles.css`.
- Новые скриншоты: PNG в `assets/img/`, WebP в двух размерах, `<picture>` с `width` и `height`.
- В `index.html` в метатегах `og:url` и `og:image` стоит адрес сайта. После подключения домена заменить его на `https://<домен>/`.

## Публикация

1. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
2. Домен: добавить файл `CNAME`; у регистратора для корня — A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, для `www` — CNAME на `<владелец>.github.io`.
3. После выпуска сертификата включить «Enforce HTTPS».
